# Getting Started with the Blazor Speed Dial Component

## Overview

This sample demonstrates how to integrate the [Syncfusion Blazor Speed Dial](https://www.syncfusion.com/blazor-components/blazor-speeddial) component into a Blazor WebAssembly application. The implementation showcases a floating action button that expands to reveal multiple action items, providing quick access to common actions from a compact user interface. The sample also demonstrates icon customization, predefined styling, and position configuration to help developers quickly understand the basic setup and customization options available in the Speed Dial component.

## Key Features

- Integrates the Syncfusion Blazor Speed Dial component in a Blazor WebAssembly application.
- Uses the `IconCss` property to display a custom add icon on the main Speed Dial button.
- Configures multiple Speed Dial action items through the component's item collection.
- Demonstrates predefined CSS class customization to modify the appearance of the Speed Dial and action items.
- Shows Speed Dial position configuration to render the component in different locations within the page.
- Illustrates the floating action button expansion behavior for accessing multiple actions from a single button.

## Prerequisites

- [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or [Visual Studio Code](https://code.visualstudio.com/)
- [.NET SDK](https://dotnet.microsoft.com/en-us/download/dotnet) compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone this repository.
2. Open the repository folder in Visual Studio 2022.
3. Restore NuGet packages.
4. Set the Blazor WebAssembly project as the startup project if required.
5. Build the project.
6. Run the application using **Ctrl+F5**.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory.

```bash
dotnet restore
dotnet run
```

4. Open the URL displayed in the terminal after the application starts.
